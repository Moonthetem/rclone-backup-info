PERSONAL GOOGLE DRIVE INTEGRATION

rclone — personal VPS backups

This page describes an owner-operated backup utility that uses the open-source rclone software to store VPS incident records in a private Google Drive account.

What the app does

The utility creates consistent backup snapshots, uploads them to the owner's Drive, and downloads them to check their contents before removing redundant local copies. It runs on the owner's VPS.

Google account access

The owner signs in using Google's OAuth consent screen. The integration requests drive.file, which allows access to files and folders created by this integration. The owner controls the Google account and can revoke access at any time.

Privacy and support

Read the privacy policy for the information handled by this integration. For support, use the user support email shown on the app's Google consent screen.
